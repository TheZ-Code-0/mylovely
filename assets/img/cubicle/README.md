# Folder Foto Toilet Cubicle

Isi folder ini dengan FOTO ASLI proyek toilet cubicle PT Hikma Langgeng Abadi.

## Cara ganti foto
1. Upload foto ke folder ini, contoh nama: `cubicle-proyek-01.jpg`
2. Buka `index.html`, cari baris:
   `<img src="assets/img/cubicle/toilet-cubicle-hla.svg" class="product-img"`
3. Ganti `assets/img/cubicle/toilet-cubicle-hla.svg`
   menjadi `assets/img/cubicle/cubicle-proyek-01.jpg`

## Saran ukuran foto
- Rasio landscape, minimal 1200 x 800 px
- Format .jpg atau .webp, ukuran file di bawah 500 KB agar web tetap cepat

File `toilet-cubicle-hla.svg` adalah ilustrasi sementara (bukan foto proyek).
Hapus atau abaikan setelah foto asli tersedia.
