# Folder Foto Atap Alderon

Isi folder ini dengan FOTO ASLI pemasangan atap Alderon oleh PT Hikma Langgeng Abadi.

## Cara ganti foto
1. Upload foto ke folder ini, contoh nama: `alderon-proyek-01.jpg`
2. Buka `index.html`, cari baris:
   `<img src="assets/img/alderon/atap-alderon-hla.svg"`
3. Ganti `assets/img/alderon/atap-alderon-hla.svg`
   menjadi `assets/img/alderon/alderon-proyek-01.jpg`

## Saran ukuran foto
- Rasio landscape, minimal 1200 x 800 px
- Format .jpg atau .webp, ukuran file di bawah 500 KB agar web tetap cepat

File `atap-alderon-hla.svg` adalah ilustrasi sementara (bukan foto proyek).
Hapus atau abaikan setelah foto asli tersedia.
